---
name: Reporting policy
description: Source, privacy, and unsupported-field decisions for the Excel report examples
---
The uploaded example workbooks are report format references, not permission to seed or overwrite company data with their example stakeholders and share limits.

**Why:** The user requested runnable reports for the existing application, not a data import.

**How to apply:** Generate reports from current records and the executed certificate/transfer ledger. Never infer authorized limits, voting rights, option pools or contributions from the reference figures. Leave unsupported values blank with explanatory notes; reject ledger inconsistencies rather than invent balancing transactions.

SSNs are masked in exports. Fully diluted values currently count recorded shares one-for-one, not hypothetical options or conversion rights. Personal information is the current profile snapshot even for an earlier ledger as-of date.

**Why:** The references contain fields the application does not yet track; assuming rights or historical personal data would produce misleading financial reports, and full SSNs are not required to run them.

**How to apply:** Keep these limitations visible in the workbook Notes and report controls. New rights, capital, or full-SSN export requirements need an explicit product decision.
