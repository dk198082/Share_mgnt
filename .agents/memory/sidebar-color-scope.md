---
name: Sidebar and highlight colors
description: The user's preferred scope for applying green in this application's design.
---
Keep the application's existing look and feel. Use the workspace's existing green only for the left navigation panel and form-field highlight states. Do not apply a broader green color scheme to pages or primary actions.

**Why:** The user likes the current look and feel and specifically limited their color request to the sidebar and highlighted fields.

**How to apply:** When changing later styles, preserve page surfaces, typography, and the main primary-action palette unless the user requests a broader change.
